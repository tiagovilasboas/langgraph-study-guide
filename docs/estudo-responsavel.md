# Estudo responsável

- Nunca inserir chaves pessoais em notebooks compartilhados ou repositórios.
- Usar dados fictícios nos exemplos públicos.
- Não redistribuir notebooks, textos, vídeos ou saídas proprietárias do curso.
- Separar o que foi observado no laboratório do que foi implementado de forma autoral.
- Validar requisitos objetivos por código e registrar erros como parte do aprendizado.
- Conferir a política do curso e a licença de cada dependência antes de publicar.
